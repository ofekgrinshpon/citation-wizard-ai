## Paid source meter (second unexecuted draft)

Run after the receipt draft and only against the exact five matching deployed function fingerprints. The prefix refuses drift. `takbull_pilot_source_usage` is private and links each source reservation to the same account's exact verified base/add-on order. It adds one new provider reservation in `begin_citation_request` (Quick and the shared runCitation path for Word/bibliography) or one deterministic paid debit in `consume_local_citation_trial`; the same owner lock serializes payment, expiry checks, and usage. Sources in a batch are billed one by one, independent of the legacy anchor. Completion/recovery and reservation state are in one transaction. Failed work releases the original bucket only, uncertain work reserves it, repeat results never execute or debit again. Refunded/expired orders stop contributing quota; previous receipts stay auditable. Only the current paid pass/add-ons contribute quota. Base is used before add-ons. Existing trial/admin/legacy processing remains the fallback when no active pilot pass exists. The status RPC adds `paid_source_meter` and `paid_pass_ends_at` for active pilot accounts, but requires appropriate client copy before activating.

Single-backend SQL results cover account isolation, local/replay/cross-route identity, two charged provider requests in one batch, provider failure/unknown/recovery/retry, exact last unit, refusal rather than paid-to-legacy spill, addon refund/base revoke/expiry, and no legacy balance changes.
