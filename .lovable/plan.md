

# תיקון טעינה איטית בדף Admin

## הבעיה

בכל טעינה של דף ה-Admin, הפונקציה `fetchData` קוראת ל-`ensureVerifiedSources` (שורות 88-93) עבור **כל** הציטוטים המאומתים מההיסטוריה. הפונקציה הזו עוברת אחד-אחד על כל ציטוט, מבצעת שאילתות DB נפרדות לכל אחד, ולפעמים גם קריאות AI verification. זה חוסם לחלוטין את הטעינה.

## הפתרון

להסיר את קריאת הסנכרון (`ensureVerifiedSources`) מתוך `fetchData`. הסנכרון כבר מתבצע בזמן אימות ציטוט בודד (`toggleVerification` / `bulkToggleVerification`), אז אין צורך לעשות אותו שוב בכל טעינת דף.

## שינויים

### `src/pages/Admin.tsx`

- **הסרת** הבלוק בשורות 78-94 (סינון ציטוטים מאומתים + קריאה ל-`ensureVerifiedSources`) מתוך `fetchData`
- `fetchData` ייראה כך: שליפת citations + profiles במקביל → שליפת verified_sources → סיום. שלוש שאילתות DB פשוטות בלבד, ללא עיבוד סדרתי.

זה אמור להוריד את זמן הטעינה מעשרות שניות לפחות משנייה.
