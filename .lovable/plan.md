

# עמוד נחיתה חדש — Hero + "איך זה עובד?" בגלילה

## סיכום

שינוי דף הנחיתה (`Landing.tsx`) למבנה של עמוד שלם: חלק עליון (Hero) עם לוגו גדול, טאגליין, כפתור "התחילו!" וכפתור כניסה למשתמש קיים — וגלילה למטה חושפת את ה"איך זה עובד?" עם 4 צילומי המסך. טופס ההתחברות/הרשמה יעבור לדף נפרד `/auth`.

## שינויים

### 1. `src/pages/Auth.tsx` — דף אותנטיקציה נפרד (חדש)

העברת כל לוגיקת ה-login/signup הקיימת מ-`Landing.tsx` לדף חדש:
- טופס התחברות/הרשמה + Google OAuth
- כפתור חזרה לדף הראשי
- אותו עיצוב של הכרטיס הקיים

### 2. `src/pages/Landing.tsx` — שכתוב מלא

**מבנה העמוד:**

```text
┌──────────────────────────────┐
│  Hero (100vh)                │
│  ┌────────────────────────┐  │
│  │  ReLex Logo (גדול)     │  │
│  │  "העוזר המשפטי         │  │
│  │   האוטומטי שלך"        │  │
│  │                        │  │
│  │  [  התחילו!  ]         │  │
│  │  כניסה למשתמש/ת קיימ/ת │  │
│  │                        │  │
│  │     ↓ גלילה למטה       │  │
│  └────────────────────────┘  │
├──────────────────────────────┤
│  "איך זה עובד?"             │
│                              │
│  שלב 1: הזן מקור  [תמונה]  │
│  שלב 2: אזכור תקני [תמונה] │
│  שלב 3: הערות שוליים [תמונה]│
│  שלב 4: תוצאה מאומתת[תמונה]│
│                              │
│  [  התחילו עכשיו!  ]        │
│  כללי האזכור האחיד...        │
└──────────────────────────────┘
```

- **Hero**: לוגו בגודל ~80px, טאגליין "העוזר המשפטי האוטומטי שלך", כפתור CTA ראשי "התחילו!" (מוביל ל-`/auth` במצב הרשמה), לינק "כניסה למשתמש/ת קיימ/ת" (מוביל ל-`/auth` במצב התחברות), חץ גלילה עדין למטה
- **סקציית "איך זה עובד?"**: 4 שלבים עם צילומי מסך בפריסה מתחלפת (תמונה ימין/שמאל), אנימציית fade-in בגלילה
- **CTA תחתון**: כפתור "התחילו עכשיו!" נוסף בתחתית
