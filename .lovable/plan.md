

# חיפוש Perplexity למאמרים (כללים 24.1–24.12)

## מה חסר

כיום המערכת מבצעת חיפוש Perplexity אוטומטי עבור פסיקה, חקיקה, תקנונים וספרים — אך **לא עבור מאמרים**. כלומר, כשמשתמש מקליד שם מחבר + שם מאמר, ה-AI מנסה לעצב אזכור ללא נתונים ביבליוגרפיים מאומתים (כתב עת, כרך, עמוד, שנה).

## שינוי נדרש

### קובץ: `supabase/functions/citation-chat/index.ts`

הוספת בלוק חיפוש Perplexity חדש — **Article search** — בין בלוק ה-Book לבין בניית ה-`enhancedMessages` (שורה ~1085).

### זיהוי — מתי לחפש

```
const isArticle = classMatch && /מאמר/.test(classMatch[1]);
```

תנאי הפעלה: `isArticle && !hasVerifiedCandidates`

זה יתפוס גם "מאמר בכתב עת" וגם "מאמר שפורסם בספר".

### פרומפט Perplexity — מאמר בכתב עת

שאילתת חיפוש:
> מצא את המאמר האקדמי/משפטי הישראלי: "{קלט המשתמש}".
> ציין: 1) שם המחבר/ים המלא (ללא תארים), 2) שם המאמר המלא, 3) שם כתב העת, 4) מספר כרך (אותיות או מספרים כמו במקור), 5) מספר חוברת (אם רלוונטי), 6) עמוד תחילת המאמר, 7) שנת פרסום לועזית, 8) שנת פרסום עברית (אם קיימת), 9) האם זה עיתון יומי ואם כן שם החלק.

סכמת JSON:
```json
{
  "found": true,
  "type": "journal" | "newspaper" | "article_in_book",
  "author": "שם מחבר",
  "articleTitle": "שם המאמר",
  "journalName": "שם כתב העת",
  "volume": "לד",
  "notebook": "",
  "firstPage": "183",
  "year": 2011,
  "hebrewYear": "",
  "newspaperSection": "",
  "newspaperDate": "",
  "bookTitle": "",
  "bookAuthor": "",
  "editor": "",
  "bookYear": 0,
  "sameAuthor": false
}
```

### פרומפט Perplexity — מאמר בספר

אם הסיווג הוא "מאמר שפורסם בספר" או שהקלט מכיל "בתוך" / "ספר", השאילתה תתמקד בפרטי הספר:
> מצא את המאמר "{שם מאמר}" שפורסם בספר. ציין: 1) שם מחבר המאמר, 2) שם המאמר, 3) שם מחבר הספר, 4) שם הספר, 5) כרך, 6) עמוד תחילת המאמר, 7) עורך/ים, 8) שנת פרסום, 9) האם מחבר המאמר זהה למחבר הספר.

### בניית ה-Hint

בדומה ל-`bookHint`, ייבנה `articleHint` עם הנתונים שנמצאו:

```
══ נתוני מאמר שנמצאו בחיפוש ══
מחבר: רונית לוין-שנור
שם מאמר: הפרטה, הפרדה והפליה
כתב עת: עיוני משפט
כרך: לד
עמוד ראשון: 183
שנה: 2011
══ השתמש בנתונים אלו לעיצוב אזכור לפי כלל 24. סמן [חסר:...] רק לשדות שאינם מופיעים. ══
```

עבור מאמר בספר, ה-hint יכלול גם פרטי הספר (מחבר, שם, עורך, שנה) ויציין אם המחבר זהה (כלל 24.11).

### אימות נגד הזיות

כמו בספרים — דרישת מינימום: `found === true` + `articleTitle` + לפחות `author` או `journalName`.

### הזרקה

שורת ה-hints תתעדכן:
```typescript
const allHints = engineHint + (verifiedHint || "") + caseLawHint + legislationHint + regulationHint + bookHint + articleHint;
```

### מקרים מיוחדים

- **"פרשת השבוע"**: אם `journalName` מכיל "פרשת השבוע", ה-hint יוסיף הנחיה: "כלל 24.12.2 — ציין פרשה לפני השנה, ללא עמוד ראשון"
- **"משפט, חברה ותרבות"**: אם `journalName` מכיל "משפט, חברה ותרבות" ושנה < 2018, ה-hint יציין: "כלל 24.12.1 — אזכר כמאמר בספר (כלל 24.11)"
- **עיתון יומי**: אם `type === "newspaper"`, ה-hint יכלול שם חלק ותאריך פרסום
