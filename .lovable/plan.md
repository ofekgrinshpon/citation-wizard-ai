### 2. חיזוק ההנחיות ל-AI ב-`supabase/functions/legal-qa/index.ts`
להחליף את שורות 1722–1733 (הבלוק "כלל קריטי – אזכורים חוזרים") בבלוק חדש מפורט שמכסה את כל הכללים של 37.2, 37.5, 37.7, 37.8 ו-37.9, עם דוגמאות:

**מבנה ההנחיה החדשה:**

- **37.2 — בחירת שם המקור:**
  - חקיקה: שם החיקוק בלבד ("חוק העונשין", לא "חוק העונשין, התשל"ז-1977").
  - פסיקה: "עניין X" / "פרשת X" / "הלכת X" — לבחור צד מזהה אחד (לא "מדינת ישראל", "פלוני", "היועץ המשפטי" אם יש חלופה).
  - ספרות: שם משפחה בלבד; אם יש שני מחברים בעלי שם זהה — להוסיף שם יצירה במירכאות.
  - **עיצוב:** שמות צדדים וספרים מודגשים `**X**`, שמות מאמרים במירכאות `"X"`, "עניין/פרשת/הלכת" ללא הדגשה.

- **37.5 — תחיקה (חריג חשוב):**
  - אסור לכתוב "לעיל ה"ש N" עבור חוק. במקום זאת: `ס' 5 לחוק העונשין.` ההפניה הספציפית באה לפני שם החיקוק.
  - דוגמה: `ס' 34יב לחוק העונשין.` (לא: "חוק העונשין, לעיל ה"ש 16").

- **37.7 — מתי 'שם' ומתי 'לעיל':**
  - הערה N+1 מצטטת את אותו מקור של הערה N, ללא מקור אחר ביניהם → `שם.` או `שם, בעמ' X.`
  - באותה הערה, מקור חוזר ללא מקור אחר ביניים → `שם.`
  - באותה הערה, מקור חוזר עם מקור אחר ביניים → `[שם], שם.`
  - בכל מקרה אחר → `[שם], לעיל ה"ש N, בעמ' X.`

- **37.8 — הפניה ספציפית:**
  - **חובה** אות שימוש בי"ת: `בעמ'`, `בפס'`, `בס'` (לא: "עמ' 45" או "בעמ 45").
  - אם "שם" מצביע על אותו עמוד — `שם.` בלבד (לעולם לא `שם, שם.`).
  - אם "שם" של חוק + סעיף שונה — `שם, בס' 2ב(2).`

- **37.9 — מקורות לועזיים:**
  - שם המקור בשפת המקור: `הלכת Brown, לעיל ה"ש 39.`
  - שמות צדדים בלועזית מוטים (במערכת: סימון `##X##`): `עניין ##Donoghue v. Stevenson##, לעיל ה"ש 52, בעמ' 580.`
  - הפניה ספציפית בעברית תמיד.

### 3. validator חדש בפוסט-פרוססינג (ב-`supabase/functions/legal-qa/index.ts`, אחרי שורה 2475)
להוסיף שלב ניקוי לתיקון הפרות נפוצות של כלל 37:

- **37.5 — חוק עם "לעיל ה"ש":** כשהערה היא בצורת `[שם חוק], לעיל ה"ש N` — להמיר לצורה הנכונה `ס' [N] ל[שם חוק].` אם יש pinpoint לסעיף; אם אין — להשאיר את שם החוק בלבד עם הסעיף.
  ```ts
  // Detect: starts with חוק/פקודת/תקנות + לעיל ה"ש
  const lawSupraPattern = new RegExp(`^((?:חוק[- ]יסוד|חוק|פקודת|תקנות|צו)\\s+[^,]+),\\s*${SUPRA_P}\\d+(?:,\\s*בס['׳]\\s*([\\d\\u0590-\\u05FFא-ת]+))?`);
  // Rewrite: "ס' X לחוק Y." or just "חוק Y."
  ```

- **37.8 — `שם, שם`:** regex להמיר `שם,\s*שם` ל-`שם` בלבד.

- **37.8 — חסר אות שימוש בי"ת:** `,\s*עמ'\s*\d+` → `, בעמ' \d+` ; `,\s*פס'\s*\d+` → `, בפס' \d+` ; `,\s*ס'\s*\d+` → `, בס' \d+` (רק בתוך הערות חוזרות, לא באזכורים מלאים שכבר משתמשים בנוסחה אחרת).
