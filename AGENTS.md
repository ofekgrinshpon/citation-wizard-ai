
- Legal assistant UI is conversation-based (research_conversations/research_messages); legal_research_jobs link via conversation_id and stay internal. Why: chat UX where jobs are an execution detail.
- Assistant chat messages are inserted only by the legal-research-v2 function (service role). Why: users cannot forge assistant replies.

- Citation-pipeline provider cost telemetry goes through `_shared/costTelemetry.ts` (`trackedFetch` + AsyncLocalStorage context) into service-role-only `ai_cost_events`; telemetry ids are never sent as billing `batchId`. Why: per-attempt USD attribution without mixing concurrent requests or changing billing.
- Cost telemetry v2: stages come from a bounded enum passed explicitly at each provider call site; zero-work (cache/deterministic) events are metadata-only (provider none, USD 0) and client-reported ones go only through the authenticated allowlisted `cost-telemetry-event` function. Why: per-attempt attribution without forgeable paid events.
- legal-research-v2 paid-provider telemetry: model.ts records each attempt via beginAttempt (observe-only, Responses SSE terminal usage), Perplexity via trackedFetch; each driveRun chunk gets its own context (request id = run UUID, batch id = per-invocation UUID). Why: per-attempt cost attribution across background/resumed chunks without changing wire requests or billing.
- Ordinary public research may use a native OpenAI route only via server switch `V2_ORDINARY_TRANSPORT` (default gateway), pinned per run at intake; it fails closed without durable per-run/day spend caps, never retries/resends uncertain calls, and never falls back to the gateway. Why: separates research spend from Lovable without silent cost or provider drift.
- Ordinary-direct repair calls checkpoint with an explicit repair phase; a resume finding it fails closed (no resend/refund), and terminal writes carry allowlisted attempt receipts from the live ledger (`shared/ordinaryReceipts.ts`). Why: never replay repair as initial research and never lose spend-reconciliation evidence.
- citation-chat case-number prompts and non-trusted snippet evidence live in `_shared/caseLawQuery.ts` (pure, tested). Why: court-aware prompts and strict evidence rules stay testable outside the handler.
- Book recovery uses `_shared/citationPure/bookFinal.ts`: render before snippet projection; bind content v2 using recursive canonical JSON (sorted objects, ordered arrays); v1 requires its exact old checksum. Replay needs authenticated-read origin and strict binding; cached warnings survive. Why: JSONB-safe context, no snippets, authority flags or verification claims.
- Citation styling is parsed by `_shared/citationPure/segments.ts`, re-exported by `src/lib/citationSegments.ts` (`**`/`##`/`^^`, backslash escapes); renderers escape literals, detection uses `citationTextOnly`, exports keep markup (`extractCitationPresentation`), identity keys use plain text (`extractCitationOnly`). Why: one server/client parser prevents marker leakage.
- Foreign-source classification (detected/overrides/effective, all 12 workbook axes) lives in `src/lib/foreignClassification.ts`; entities use stable ids separate from edition table locators (`src/data/bluebook/classification/`). Records are client-local per account, keyed by a stable item key (chat position / batch cell key / bibliography classificationKey), never call the network, and only a successful explicit generation using the exact plan may mark output fresh. Why: deterministic isolated choices that cannot fake renderer support or freshness.
- Foreign statute lookup (US/UK only) is a typed contract: client request/response adaptation lives only in `src/lib/foreignStatuteAdapter.ts`, and the server resolves it only via `citation-chat/statuteRoute.ts`, which always returns a versioned typed result and never falls through to the generic model. Merge only matched, conflict-free, same-jurisdiction results whose identity matches an official record path consistent with the extracted citation. Why: no crossed manual choices, fabricated fields or silent model fallback.
- Local foreign formatters run in chat and runCitation only for their exact effective source type and only on explicit supplied structure; contradictions or ambiguity are preserved with a warning. Why: complete supplied forms need no provider, and formatting must never guess identity or route siblings through a formatter.
- Pasted safety precedes cache/usage; hosts/recovery share `citationPlanner.ts`/`citationCompletion.ts`. Books/chapters need explicit anchors, supported missing fields and distinct donors. Recovery reparses exact bound raw, checks wire/manual constraints, never trusts retained metadata. Local fields/spans stay separate from wire; supplied values win. Edition normalization is render-only; metadata is transient. Why: no invented evidence or IO.
- `_shared/citationPure/rulepack.ts` (`rulepackCapability`) decides local/typed/server routes by family+jurisdiction, with exact template IDs required for AU/CA local routes; disabled country packs keep raw with zero IO (not general literature); ids use its mapping, never cast to US/IL/UNKNOWN. Why: one contract.

- AU/CA local evidence and style roles live in `_shared/citationPure/countryLocal.ts`, reused by the shared host planner; identified unsupported/incomplete forms are terminal before cache/classifier/provider, and completion remains disabled. Why: one browser/Deno grammar and no country fallback or identity claims.
